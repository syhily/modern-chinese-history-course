# 《中国近现代史》EPUB 制作约定

本项目把扫描版《中国近现代史》（章开沅、朱英主编，河南大学出版社 2009 年 8 月第 1 版）制作成 EPUB 3。**正文文字以 MinerU pipeline 模式识别结果为校对底稿**（`ocr/pipeline/`，无幻觉），**vlm 模式结果用于交叉比对**（`ocr/vlm/`，复杂版式更准但偶有幻觉），**一切分歧以 PDF 原书渲染页为准**。

## 目录结构与素材

- `source/中国近现代史.pdf` — 扫描件（705 页）
- `ocr/pipeline/pages-NNN-NNN.md`、`ocr/vlm/pages-NNN-NNN.md` — MinerU 双模式 OCR 结果（100 页/片，文件名数字为 **PDF 页码**）
- `manuscript/chNN.md` — 十三章正文（NN = 01…13）；`manuscript/00-frontmatter.md` 前置；`manuscript/14-postscript.md` 后记
- MinerU 会**系统性漏收页底圈码注文**，但正文中的圈码 ①②③ 位置基本齐全；标题一律识别为 `##`，转换时必须按下表重新定级

## 原书页码 ↔ PDF 页码换算

渲染原书页面用 Ghostscript（输出文件序号从 1 起，注意换算）：

```bash
gs -dNOPAUSE -dBATCH -sDEVICE=jpeg -r150 \
  -dFirstPage=122 -dLastPage=172 \
  -sOutputFile=/tmp/pages-ch03/page-%03d.jpg source/中国近现代史.pdf
# /tmp/pages-ch03/page-001.jpg = PDF 第 122 页 = 原书第 111 页
```

**节省上下文的技巧**：核对脚注时不必看整页，渲染后用 ImageMagick 裁出页底约 1/4 区域再看；也可把若干页页底纵向拼成大图一次扫多页：

```bash
magick /tmp/pages-ch03/page-001.jpg -gravity South -crop 100%x25%+0+0 +repage /tmp/pages-ch03/foot-001.jpg
```

## 标题层级

| 层级 | 内容 | 示例 |
|---|---|---|
| `#` | 章题（第 N 章 XXX） | `# 第三章 新社会结构的发生` |
| `##` | 第 N 节；本章小结／学术综述／参考书目／思考题 | `## 第一节 社会结构的基本状况`、`## 本章小结` |
| `###` | 目（一、二、…） | `### 一、君权与官僚政治` |
| `####` | 小节（1. 2. …） | `#### 1. 高度强化的皇权` |
| `#####` | 小小节（（1）（2）…，若出现） | `##### （1）……` |

- 构建用 `--split-level=1`，**每章拆为一个文件**，章内各节连续排版；不要在章内手动加 `\newpage`（pandoc 生成 nav 目录时会吞掉 unlisted 空标题之后的节标题）。
- 第一章章题跨两行（「第一章 前近代时期的中国社会：／1500～1840」），Markdown 写一行即可：`# 第一章 前近代时期的中国社会：1500～1840`。
- MinerU 输出中所有标题都是 `##`，**必须按上表逐条重新定级**；`###` 目级标题会进入 EPUB 目录（toc-depth=3），`####` 及以下不进目录。
- 章末四栏目（本章小结、学术综述、参考书目、思考题）原书为居中黑体标题，一律作 `##` 处理，进入目录。

## 脚注（重点，必须对照原书核对）

原书脚注是**页底圈码 ①②③，每页重新编号**。MinerU 两种模式都会系统性漏收页底注文，因此：

1. **标记位置**：pipeline/vlm 正文中的圈码位置基本齐全，可作为锚点；发现正文有圈码位置疑问时渲染原页裁决。
2. **注文补回**：逐页检查页底（裁页底 25% 区域看图，多页拼大图效率更高）。数正文圈码与页底注文是否成对；无圈码的页每隔几页抽查页底。
3. 注文转为 pandoc 行内脚注 `^[注文]`，紧跟圈码所在字句之后；不使用 `[^n]` 编号式脚注。
4. 脚注内的文献信息（如 `2003(3)`）照原书保留半角括号；「参见」「以上参见」等措辞照录。
5. 自查：`grep -o '\^\[' manuscript/chNN.md | wc -l` 即该章脚注数，与校对记录核对。

## 引文、表格与其他版式

- 正文中**单独成段的引文**（原书缩进排）用 Markdown blockquote（`> `），EPUB 中渲染为楷体缩进块。拿不准时渲染原书页确认。
- 表格用 pandoc pipe table，不使用合并单元格；跨页表格的「（续表）」删除并合并；表题独占一行：`[……表（……）]{.biaoti}`（加粗居中）。
- 数字/年份范围统一全角浪纹线 `～`（如 `1500～1840`）；半角 `-` 仅保留于 ISBN 等西文编号。
- 正文括号统一全角（）；原书印半角的也统一为全角。
- 原书自身误植**照录不擅改**，加 HTML 注释 `<!-- 疑：原书作「x」 -->`；OCR 讹误据原书改正并加 `<!-- 校：OCR 作「x」 -->`。校勘注释不会进入 EPUB（构建时剥离）。
- 删除杂质：页眉（「中国近现代史」「第X章 …」+ 页码）、页底页码、`![](images/…)` 残留；合并跨页断段（含 OCR 分片边界处）。
- 段落之间空行分隔；删除行内多余全角空格、tab。

## 输出与自查

每章输出一个文件 `manuscript/chNN.md`（NN = 01…13），文件开头第一个非空行必须是 `# 第N章 章题`。完成后执行：

```bash
grep -n '\[[0-9]' manuscript/chNN.md        # 必须无输出（无 [n] 残留；^[1980年…] 类以数字开头的注文是误报，人工看一眼）
grep -n "$(printf '\t')" manuscript/chNN.md # 必须无输出（无 tab；macOS 的 grep 没有 -P）
grep -o '\^\[' manuscript/chNN.md | wc -l   # 该章脚注总数
grep -n '!\[' manuscript/chNN.md            # 必须无输出（无图片残留）
```

不要运行 `make build`（全书未齐时构建无意义）；不要改动 `manuscript/` 以外的任何文件。
